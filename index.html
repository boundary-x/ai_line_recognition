1. 카메라 설정

카메라 버튼을 통해 화면을 설정해주세요.

2. 기기 연결

블루투스 연결 버튼을 클릭해 마이크로비트를 연결해주세요.

상태: 연결 대기 중

3. 라인 인식 설정

조명과 바닥 색상에 맞게 선이 잘 인식되도록 조절하세요.

현재 값: 100
화면 하단 30% 사용

흑백 보기에서 선은 흰색, 배경은 검은색이 되도록 라인 구분 기준을 조절하세요.

4. 주행 설정

민감도를 높이면 더 크게 회전합니다. 조절하면 전송이 중지됩니다. 미리보기를 확인한 뒤 다시 시작하세요.

원리 보기

① 선의 위치 찾기 → ② 중앙과의 차이 계산 → ③ 좌우 바퀴 속도 조절

왼쪽 바퀴가 느리면 왼쪽으로, 오른쪽 바퀴가 느리면 오른쪽으로 회전합니다.

라인이 감지되면 계산 과정이 나타납니다.

속도는 0~140으로 제한하며 후진하지 않습니다. 기본 속도 0이면 양쪽 모두 정지합니다. 카메라를 로봇에 고정하면 움직인 결과를 다시 보고 방향을 바로잡습니다. 선은 학습 모델이 아닌 영상의 밝기 차이로 찾습니다.
